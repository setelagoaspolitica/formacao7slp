# Cursos

Cada curso fica em uma pasta própria. Para criar uma nova formação:

1. Crie uma pasta com um identificador simples, por exemplo `curso-de-cidadania`.
2. Coloque nela um `course.json` seguindo o modelo de `formacao-centro-esquerda`.
3. Coloque os PDFs na pasta `pdf/` do curso.
4. Coloque os vídeos e podcasts no `links.txt` do curso.
5. Crie ou copie um `course-content.js` com módulos, resumos, referências e perguntas.
6. Cadastre o curso no catálogo da plataforma.

O aluno escolhe a formação antes de entrar. O modelo mantém leitura, mídia, caderno, provas, progresso, gamificação e certificado separados por curso quando o conteúdo for cadastrado para produção.
