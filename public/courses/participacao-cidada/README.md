# Participação Cidadã

Este curso foi criado para trabalhar cidadania, organização comunitária e ação coletiva em um território real.

## Estrutura
- 4 módulos
- leitura, mídia e prova por módulo
- foco em participação, democracia local e propostas de intervenção

## Materiais
